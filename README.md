# HAYK Loyalty Club ☕

سایت باشگاه وفاداری کافه با ظاهر دقیقاً مطابق طرح ارسالی. یک سایت استاتیک (HTML/CSS/JS خالص، بدون نیاز به build) که داده‌هاش روی **Supabase** (دیتابیس رایگان) ذخیره می‌شه و روی **Vercel** میزبانی می‌شه.

## ساختار سایت

| صفحه | کاربرد |
|---|---|
| `index.html` | صفحه اصلی با ۳ دکمه (دقیقاً مطابق عکس) |
| `join.html` | فرم عضویت مشتری جدید (نام + موبایل، بدون محدودیت تعداد) |
| `dashboard.html` | صفحه اختصاصی هر مشتری: پیشرفت، QR کد، و بخش قفل‌شده‌ی کارکنان برای افزودن نوشیدنی |
| `login.html` | ورود مشتری با شماره موبایل |
| `staff-admin.html` | ورود ادمین با یوزرنیم + پسورد |
| `admin.html` | جدول کامل مشتری‌ها با امکان ویرایش/حذف/افزودن نوشیدنی + تنظیمات رمزها |

### منطق نوشیدنی رایگان
هر مشتری `drink_count` داره که از ۰ تا ۷ بالا می‌ره. وقتی به ۷ رسید، نوشیدنی بعدی (هشتمی) رایگان حساب می‌شه و شمارنده دوباره صفر می‌شه. این عدد در `js/config.js` با متغیر `DRINKS_FOR_FREE` قابل تغییره.

### منطق QR کد
هر مشتری بعد از عضویت یک QR کد اختصاصی می‌گیره که به آدرس `dashboard.html?id=<شناسه>` اشاره می‌کنه. وقتی کارمند این کد رو با دوربین گوشیش اسکن می‌کنه، مستقیم صفحه‌ی همون مشتری باز می‌شه. پایین صفحه یک باکس «دسترسی کارکنان» هست که با وارد کردن رمز عبور کارکنان باز می‌شه و دکمه‌ی «+۱ نوشیدنی» رو فعال می‌کنه — دقیقاً همون سناریویی که خواسته بودید. نیازی به اسکنر داخل سایت نیست؛ دوربین پیش‌فرض گوشی کافیه.

رمزهای پیش‌فرض (حتماً بعد از راه‌اندازی عوضشون کنید، از داخل پنل ادمین → تنظیمات):
- رمز کارکنان: `staff123`
- یوزرنیم ادمین: `admin` / رمز ادمین: `admin123`

## مرحله ۱ — ساخت پروژه‌ی Supabase (دیتابیس رایگان)

1. به [supabase.com](https://supabase.com) برید و یک حساب رایگان بسازید.
2. یک پروژه جدید بسازید (یک رمز دیتابیس هم ازتون می‌خواد بسازید، جایی یادداشتش کنید).
3. از منوی سمت چپ وارد **SQL Editor** بشید → **New query**.
4. کل محتوای فایل `supabase/schema.sql` (همراه این پروژه) رو کپی و اجرا (Run) کنید. این کار جدول مشتری‌ها و تنظیمات رو می‌سازه.
5. از منوی **Project Settings → API** دو مقدار رو بردارید:
   - **Project URL**
   - **anon public key**

## مرحله ۲ — وصل کردن سایت به Supabase

فایل `js/config.js` رو باز کنید و این دو خط رو با مقادیر خودتون جایگزین کنید:

```js
const SUPABASE_URL = "https://xxxxxxxx.supabase.co";
const SUPABASE_ANON_KEY = "eyJhbGciOi....";
```

## مرحله ۳ — آپلود روی GitHub

1. یک ریپازیتوری جدید (مثلاً `hayk-loyalty`) در گیت‌هاب بسازید.
2. همه‌ی فایل‌های این پوشه رو داخلش push کنید:

```bash
cd hayk-loyalty
git init
git add .
git commit -m "HAYK Loyalty Club"
git branch -M main
git remote add origin https://github.com/USERNAME/hayk-loyalty.git
git push -u origin main
```

## مرحله ۴ — دیپلوی روی Vercel

1. وارد [vercel.com](https://vercel.com) بشید و با گیت‌هاب لاگین کنید.
2. **Add New → Project** رو بزنید و ریپازیتوری `hayk-loyalty` رو انتخاب کنید.
3. چون سایت استاتیکه، Vercel به‌صورت خودکار تشخیص می‌ده و نیازی به تنظیم build command نیست (Framework Preset را روی **Other** بذارید).
4. دکمه‌ی **Deploy** رو بزنید. بعد از چند ثانیه یه آدرس مثل `hayk-loyalty.vercel.app` بهتون می‌ده — سایتتون آماده‌ست.

اگه دوست دارید دامنه‌ی اختصاصی خودتون (مثل `haykcoffee.com`) رو وصل کنید، از تب **Domains** همون پروژه‌ی Vercel اینکارو انجام بدید.

## نکات امنیتی مهم

- رمزهای کارکنان/ادمین همون لحظه که پنل ادمین رو باز می‌کنید (⚙️ تنظیمات) قابل تغییرن — حتماً همون اول عوضشون کنید.
- چون سایت auth واقعی (مثل ورود با ایمیل) نداره و بررسی رمزها سمت مرورگره، این یک راه‌حل مناسب برای یک کافه‌ی کوچیکه، نه یک سیستم بانکی. اگه در آینده امنیت بیشتری لازم داشتید، می‌شه با Supabase Auth یک لایه‌ی احراز هویت واقعی اضافه کرد.
- شماره موبایل مشتری‌ها به‌عنوان کلید یکتا استفاده می‌شه (هر شماره فقط یک بار می‌تونه عضو بشه)، ولی هیچ محدودیتی روی تعداد کل مشتری‌ها وجود نداره.

## تست محلی (اختیاری)

چون سایت کاملاً استاتیکه، کافیه با یک سرور ساده لوکال باز بشه (به خاطر fetch API نمی‌شه مستقیم فایل رو با دوبل‌کلیک باز کرد):

```bash
npx serve .
# یا
python3 -m http.server 5500
```

سپس `http://localhost:5500` رو باز کنید.
